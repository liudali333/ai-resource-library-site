HELP / 使用指南

从一次发现，
开始积累。

说明对应当前 0.7.x 版本 · Chrome 商店审核中

先确认目标共享表的访问权限，再用自己的腾讯文档账号授权。之后，网页投稿、截图和群资源卡片，都可以在浏览器里完成。

开始之前

  • 使用 Chrome 或 Edge 127 及以上版本，并允许插件在需要显示悬浮入口的网页运行。
  • 确认自己拥有群共享表的访问权限；投稿还需要编辑权限。当前版本使用群管理员预设的腾讯智能表格。
  • 每个人使用自己的微信或 QQ 账号授权，不使用群主或其他群友的 Token。
  • 插件的部分能力依赖腾讯文档官方接口。接口或会员要求以腾讯平台实际提示为准，插件不能绕过这些限制。

Chrome 商店链接将在审核发布后补充。本站目前没有提供商店安装入口，也不要求你在官网填写账号密码或 Token。

提交网页资源

  1. 打开想分享的网页。点击浏览器工具栏中的插件图标，或使用网页右键菜单的投稿入口。
  2. 核对标题和链接。插件会带入当前网页信息，你可以修改描述。分类从目标表格读取；日期固定为提交当天。
  3. 按需附上截图。截图不是必填项，可先预览、删除再决定提交。
  4. 点击提交。首次使用或授权失效时，会打开腾讯官方授权页。完成微信或 QQ 授权后返回插件，选好分类，再确认提交。
  5. 留意提交结果。只有腾讯接口确认新增记录后才显示成功；结果不明确时，先在共享表里搜索链接，确认没有写入后再重试。

有效个人授权会在本机记住，重启浏览器后可以继续复用；腾讯撤销或使授权过期后仍需重新授权。提交面板会在接口可用时显示当前授权账号昵称。

连续截图与上次区域

  1. 在投稿面板点击「添加截图」，在当前网页可见区域拖动框选。
  2. 截好后，可以点击「继续截图」，或先滚动网页再继续选择另一处。
  3. 当前会话会记住上次框选区域；窗口大小相同时，可使用「截上次区域」。
  4. 点击「截图完成」回到面板，查看缩略图并删除不需要的图片。
  5. 每次最多附加 5 张，点击提交时和资源一起发送到腾讯文档的图片列。

截图与草稿只在当前浏览器会话中临时保留，不保存成图片文件。退出浏览器或临时数据失效后，未提交内容可能丢失。浏览器内部页、扩展管理页等禁止注入的页面不能框选。

用悬浮卡片查看群资源

  • 数字：表示共享表「日期」列属于北京时间今天的条数，不是全部条数。
  • 红点：表示自上次查看更新后出现了新记录。打开更新后清除本批提示，不是逐条阅读统计。
  • 上一条 / 下一条：浏览整个共享表的资源，不限今天。新资源出现时会提示，不会强制跳走当前条目。
  • 图片与链接：有可用图片时显示配图，右上角可以打开资源，左上角「群共享库」可跳转到表格。

共享表约每分钟检查一次。排序优先使用创建时间字段；表中没有该字段时按日期排序，同一天的精确先后以接口返回顺序为准。

常见问题

为什么有些网页没有悬浮图标？

确认扩展已启用并获准在该网站运行，更新扩展后需刷新网页。浏览器内部页、应用商店、部分 PDF 和禁止注入的页面不支持悬浮入口。

授权成功，为什么仍不能投稿？

授权只是确认你自己的身份，不会自动授予目标表格编辑权。请先检查共享表权限，再查看腾讯文档返回的会员或接口提示。

有图片却没有显示，怎么办？

保持腾讯文档网页登录有效，重新打开资源卡片；若插件提供「复制图片检查结果」，可复制后邮件反馈。检查结果不包含 Token、Cookie 或完整签名图片链接。不要另外附上这些凭据。

提交结果不明确，能直接再点一次吗？

先在腾讯文档搜索该链接，确认尚未写入，再使用允许重试的入口。直接重复提交可能产生重复记录，插件不提供全群跨用户去重。

为什么来源 / 分享人没有自动填上？

当前表格中的来源 / 分享人是成员字段，不能直接把昵称当文字填入。当前版本需要在腾讯文档内按权限补充该字段。

卸载后，群表里的资源也会消失吗？

不会。卸载通常会清除扩展本机数据，但已提交到腾讯文档的记录与图片仍由腾讯文档和表格权限管理。
