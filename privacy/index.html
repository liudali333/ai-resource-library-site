PRIVACY / 隐私说明

分享之前，
先把数据的去向说清楚。

生效与最近更新日期：2026 年 11 月 15 日 · 适用于当前 0.7.x 版本的功能

AI资源共享库是一款帮助群组向腾讯文档共享表提交网页资源、截图，并查看共享资源的浏览器插件。本政策说明插件及本介绍网站如何处理数据。开发者不另设收集插件资源或授权凭据的服务器，也不出售用户数据。

1. 适用范围与服务主体

本政策适用于「AI资源共享库」浏览器插件及本网站。开发者为 AI资源共享库独立开发者；联系邮箱为 1120374193@qq.com。本产品与腾讯、Google 无隶属关系；腾讯文档与 Chrome Web Store 的服务分别受其自身条款及隐私规则约束。

本官网仅介绍产品、提供使用说明和联系渠道，不在网页上索要腾讯文档 Token，不代理登录，不接收插件中的共享资源或截图。

2. 插件会处理哪些数据

数据用途与处理方式
个人授权凭据用户在腾讯官方页面完成微信或 QQ 授权后，插件取得本人授权凭据，用于访问本人有权限的腾讯文档。凭据保存在本机扩展存储，不发送给开发者。
授权账号昵称在接口可用时从腾讯文档读取，用于在提交面板识别当前授权账号；按授权身份隔离缓存，不从其他群友的分享记录推断账号名称。
网页标题、链接与表单内容用户打开投稿面板或调用右键投稿时，读取所选网页或链接的信息，供用户核对。用户点击提交后，才将资源标题、链接、分类、当天日期等发送到目标腾讯文档。
用户选择的截图用户主动点击截图并框选网页可见区域时生成截图。只有用户提交资源时，才将所附图片上传腾讯文档并关联到目标表格；截图可能包含用户选定区域中的个人或他人信息。
共享表记录与图片使用个人授权读取目标表中的标题、日期、链接、分类、图片等，用于显示今日条数、资源卡片与翻页。为显示图片，可能读取目标腾讯文档页面已有的表格响应、已加载图片及图片服务返回内容。
记录编号与更新状态在本机保存已知记录编号及更新标记，以判断是否出现新条目、显示红点，并防止本次会话重复提交。不是完整浏览历史，也不建立独立资源收藏库。
主动复制的检查结果仅在用户点击复制时写入剪贴板，供用户自行选择是否反馈。内容包含版本、图片字段键名、条数、图片主机名及错误代码，不包含 Token、Cookie、完整签名链接或图片正文；不会自动发送给开发者。

悬浮入口会在允许的普通网页显示，但不会因此持续记录或上传网页正文、浏览历史。截图不包含浏览器工具栏或桌面；未主动使用截图功能时，插件不会自动截屏。

3. 数据保存、时长与删除

浏览器本机持久存储

个人授权凭据及记录编号更新基线保存在扩展本地存储，不通过浏览器同步服务共享。授权信息的存储访问限制在可信扩展环境，普通网页脚本不能直接读取。浏览器本地存储不是独立的加密保险库。

浏览器会话内存

资源列表摘要、账号昵称缓存、待提交表单及截图用于当前浏览器会话。昵称缓存按授权身份隔离；草稿与截图设有约 30 分钟有效期，在后续访问时检查并清理。提交确认成功后清除对应表单内容和截图；为防止重复提交，本次会话可能短暂保留已提交链接与记录编号。退出浏览器会清除会话存储。

腾讯文档云端

提交成功的资源与图片保存在腾讯文档，由目标表格的访问设置和腾讯服务规则管理。拥有表格权限的成员可能看到这些内容。卸载插件不会删除已经提交到腾讯文档的记录；如需修改或删除，请在腾讯文档中按相应权限操作。

用户控制

用户可在浏览器扩展管理页禁用或卸载插件、撤销网站访问权限，或清除扩展存储；也可到腾讯官方授权页面撤销或重置授权。卸载插件通常会清除该扩展的本机存储，但不会自动撤销腾讯端已发放的凭据。隐私相关问题可通过本页邮箱联系开发者。

4. 为什么需要浏览器权限

权限或访问范围对应的用户可见功能
activeTab、contextMenus在用户调用时读取当前网页标题与链接、提供右键投稿，以及截取当前网页可见区域。
storage记住本人授权，临时保存投稿与截图状态，维护本机资源更新标记。
alarms检查授权完成情况及共享表更新，不要求用户一直保持投稿面板打开。
scripting在主动截图时显示区域选择工具；在指定的腾讯文档页面读取与目标资源匹配的图片预览。
普通 HTTP / HTTPS 网页内容脚本显示悬浮入口与资源卡片。并非持续收集所有网页内容；网页内部页、商店等禁止注入的页面不支持。
腾讯文档及腾讯图片域名授权、读写目标表格、上传截图并读取资源图片。
declarativeNetRequestWithHostAccess仅对本插件发起、目标为 docimg 数字子域的图片 GET 请求设置腾讯文档来源信息，以处理图片来源校验；不修改用户其他网页的请求，不把授权 Token 传给图片域名。

5. 第三方、数据使用与共享限制

用户选择提交的资源和截图会发送到腾讯文档及其图片服务，这是投稿功能的必要步骤。读取图片时，浏览器可能向相应腾讯域名发送该域自身的登录 Cookie；插件不读取或导出 Cookie 内容。授权凭据只用于腾讯文档接口，不经开发者服务器转存，也不会作为图片请求头转发。

开发者不出售用户数据，不将数据用于广告定向、信用评估或与上述功能无关的用途，不提供广告或第三方行为分析 SDK。用户数据仅用于已披露的、用户可见的插件功能，遵守 Chrome Web Store 用户数据政策及 Limited Use 限制。

本介绍网站不设账号系统、投稿表单、广告或第三方统计脚本。网站托管平台可能处理提供与保护网页服务所需的正常访问日志，例如 IP 地址、访问时间和浏览器信息；这不包含插件中的授权凭据或资源内容。

6. 安全与使用提醒

与腾讯服务的连接通过 HTTPS 进行。请在提交前核对网页信息与截图范围，不要把密码、身份凭证或不适合共享的私人资料上传到群表；不要向开发者或其他群友提供个人 Token。开发者不要求用户通过邮件发送 Token 或 Cookie。

插件不能替代目标表格的权限设置，也不会因为安装插件就自动取得编辑权限。授权过期、平台会员要求、接口变化或表格权限变化，可能影响功能可用性。
